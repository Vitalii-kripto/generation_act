# Генератор Актов приема-передачи

Приложение для автоматической генерации актов приема-передачи на основе УПД и спецификаций с использованием ИИ (Gemini API).

## Архитектура

Проект состоит из двух частей:
- **Frontend**: React + Vite + Tailwind CSS.
- **Backend**: Python + FastAPI + SQLite.

## Требования

- Node.js (v18+)
- Python (3.10+)
- Ключ API Gemini (GEMINI_API_KEY)

## Запуск проекта (Режим разработки)

### Способ 1: Запуск через npm (Рекомендуемый)

1. Установите зависимости frontend:
   ```bash
   npm install
   ```
2. Запустите единый скрипт разработки:
   ```bash
   npm run dev
   ```
   Этот скрипт автоматически:
   - Установит зависимости Python (если необходимо).
   - Подберет свободные порты для backend (начиная с 8001) и frontend (начиная с 3000).
   - Запустит оба сервиса.
   - Откроет браузер по готовности.
   - Будет писать логи в консоль и в файл `logs/app.log`.

### Способ 2: Запуск из PyCharm (Одной кнопкой)

1. Откройте `Run | Edit Configurations`.
2. Создайте новую конфигурацию типа **Python**.
3. В поле **Script path** укажите путь к файлу `run_dev.py`.
4. В поле **Python interpreter** выберите ваш интерпретатор из `.venv`.
5. В поле **Working directory** укажите корневую папку проекта.
6. Нажмите зеленую кнопку **Run**.

## Логирование

Все логи приложения, включая вывод frontend и backend, а также системные ошибки, записываются в файл:
`logs/app.log`

## Автоматический выбор портов

Если стандартные порты (3000 для frontend, 8001 для backend) заняты, скрипт запуска автоматически найдет следующие свободные порты и корректно настроит проксирование запросов от frontend к backend.
