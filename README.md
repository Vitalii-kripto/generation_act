# Генератор Актов приема-передачи (Node.js + React)

Это приложение предназначено для автоматизации создания Актов приема-передачи на основе данных из УПД (Универсальных передаточных документов) с использованием ИИ (Google Gemini) для распознавания текста.

## Структура проекта

- `server.ts` — Бэкенд на Node.js (Express). Отвечает за работу с базой данных SQLite и генерацию файлов Word (DOCX).
- `src/` — Фронтенд на React + TypeScript. Красивый интерфейс для пользователя.
- `acts.db` — База данных SQLite (создается автоматически).
- `package.json` — Список зависимостей для Node.js.

## Как запустить проект локально

### 1. Подготовка окружения
1. Убедитесь, что у вас установлен [Node.js](https://nodejs.org/).
2. В терминале установите зависимости:
   ```bash
   npm install
   ```

### 2. Запуск проекта
1. Запустите сервер и фронтенд одной командой:
   ```bash
   npm run dev
   ```
   Приложение откроется в браузере по адресу `http://localhost:3000`.

## Основные возможности
- **Распознавание УПД**: Загрузите скан или фото УПД, и ИИ автоматически заполнит таблицу товаров и реквизиты.
- **База данных**: Все созданные акты сохраняются в SQLite. Вы можете вернуться к ним позже, отредактировать или удалить.
- **Экспорт в Word**: Генерация полноценного документа DOCX, готового к печати и подписанию.
- **Сверка со спецификацией**: Возможность загрузить спецификацию к договору для автоматической проверки цен и наименований.
- **Подробное логирование**: Ошибки и важные события записываются в файл `app_error_log.txt` на сервере для удобного выявления проблем.

## Технологии
- **Backend**: Node.js, Express, SQLite (better-sqlite3), docx.
- **Frontend**: React 19, TypeScript, Tailwind CSS, Lucide Icons.
- **AI**: Google Gemini API (через `@google/genai`).
